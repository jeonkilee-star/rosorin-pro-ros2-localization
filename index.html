  3. 2차 — 나머지 전체사용자 지시로 범위 확장. 91개 파일을 6개 배치로 나눠 나머지 모든 중국어 텍스트를 번역.

03⚠ 음성 명령어(ASR) — 별도 주의 필요

오프라인 음성인식 하드웨어(WonderEcho Pro)는 원래 중국어 발화를 인식하도록 만들어진 모듈입니다. 명령어 텍스트를 의미상 한국어로 번역하긴 했지만, 실제 하드웨어가 그 한국어 발음을 인식하는지는 검증되지 않았습니다 — 로봇으로 직접 말해보기 전까지는 확정할 수 없습니다.

마스터 명령어 목록 (wonder_echo_pro_node.py · zh_cmd) 31개 중 28개는 이번 세션의 에이전트 보고서에 실제로 인용된 원문을 근거로 복원 가능합니다. 하드웨어가 중국어 발화용이라는 점을 고려해, 중국어 원문 + 한글 발음 표기를 기본으로 하고 의미 번역은 참고용으로 뒤에 배치했습니다. 소스 파일은 실제 words == '…' 비교 로직이 있는 개별 기능 파일이며, 31개 전부 wonder_echo_pro_node.py의 마스터 목록에도 공통으로 등록되어 있습니다:

05원본 보존 상태

모든 파일은 같은 경로에 덮어쓰기되었습니다 — 별도 백업은 만들지 않았습니다. 이 작업 폴더 자체는 git 저장소가 아니고 로컬에 원본 zip도 없지만, 사용자가 원본 zip 파일을 별도로 보관 중임을 확인했습니다.

06권장 후속 조치

  1. 미확인 3개 명령어 원문 확인원본 zip에서 초록색 집기 / 정지 / 드리프트 세 줄의 실제 중국어를 확인해 채워넣기
  2. 마스터 ↔ 개별 파일 표현 통일위 4건의 문구 불일치를 원본 대조 후 하나로 정리 (또는 원래도 달랐다면 그대로 유지)
  3. 실제 하드웨어로 31개 명령어 검증로봇 마이크에 대고 번역된 한국어 문구를 실제로 말해보고, ASR이 인식하는지 하나씩 확인 — 인식 안 되면 발음 표기(음차) 방식 재검토 필요
  4. 번역본 백업지금 한국어로 번역된 버전을 별도 압축·보관해 향후 비교 기준으로 사용
